# Add_Student_To_Student_Program

## Installation

Required files

To ensure the script runs correctly, place the following files in the same directory as the Python scripts.

`TAFdb_config.json`

- A JSON file containing the necessary credentials and configuration to connect to the database.

Mkae sure the following Python libraries are installed:

- pandas
- pyodbc
- tqdm

Use `pip install pandas pyodbc tqdm` to install them
